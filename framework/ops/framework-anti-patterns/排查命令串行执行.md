# 排查命令串行执行

## 现象

工具命令报错 `command not found` → 先查安装位置 → 等结果 → 再补依赖 → 再试 → 再看帮助。每一步等上一步完成才走下一步，用户干等。

## 后果

- 排查阶段响应延迟累积，用户感知"LLM 很慢"
- 独立诊断步骤本可并行完成（路径检查、依赖检查、CLI 帮助互不依赖）

## 正确做法

命令报错时并行发起诊断：`pip show` + `ls Scripts/` + `--help` 同时跑。三个结果一起看，一步到位给出正确命令。
