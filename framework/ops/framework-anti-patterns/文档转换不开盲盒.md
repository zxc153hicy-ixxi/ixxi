# 文档转换不开盲盒

## 现象

用户给出 PDF → LLM 直接调用 Marker 转换 → 408 页文字型 PDF 跑了 1.5 小时。

## 后果

- 纯文字型 PDF 用 Pandoc/MarkItDown 秒级完成，Marker 慢百倍
- 首次运行还触发 1.35GB 模型下载，额外等待 6-8 分钟
- Token 浪费严重——不停读后台进度条几千行控制字符

## 正确做法

先用 `python .claudian/prescan.py` 采样判断，输出推荐工具后再转换。见 [[../patterns/转换前预扫描]]。
