# 钩子越界

让 hook 去做需要语义判断的事——比如自动判断当前是什么操作并更新对应计数器。

## 根因
- hook 只能拿到工具名（Write/Edit/Bash），不知道 LLM 在做什么任务
- 把需要理解上下文的事交给机器，结果不可靠

## 修复
- counter-inc.sh 移除
- 计数器更新仍由 LLM 按规则手动执行
- 钩子系统设计原则：只做纯机械，不碰语义判断
