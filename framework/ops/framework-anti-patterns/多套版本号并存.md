# 多套版本号并存

AGENT.md、设计方案、git tag 各自有不同版本号，导致无法判断哪个才是权威版本，后续同步容易出错。

## 根因
- 设计方案单独升级，AGENT.md 未同步
- 没有自动检测机制

## 修复
- 统一为唯一版本源（AGENT.md）
- check-version-sync.sh 自动比对
