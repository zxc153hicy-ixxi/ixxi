# Obsidian 操作指引与用户版本不匹配

## 反模式
不确认版本号就给出 UI 操作指引（图谱过滤器位置等）。用户反复指出后才更换方案。

## 正确做法
涉及 Obsidian 等软件操作时，先问版本号。1.12.x 图谱过滤使用顶部搜索框 `-path`/`-file` 语法。
