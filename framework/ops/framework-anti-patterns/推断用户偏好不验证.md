# 推断用户偏好不验证

## 现象
创建 profile.md 时自动填入「框架正确的前提下，倾向先执行再微调」。
LLM 无法判断框架正确性，这条推断在逻辑上不成立。

## 根因
从单次会话行为反推用户偏好时，没有自检「我是否有能力做出这个判断」。

## 纠正
推断项必须标注 inferred: true 且向用户确认。超出 LLM 能力范围的推断不应出现在 profile 中。
