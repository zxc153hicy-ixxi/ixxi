# 单任务后遗忘全局

## 现象
完成当前步骤后直接汇报「完成」，忘记检查全局待办清单。多次被用户追问「X没收尾」才回头补。

## 根因
完成当前任务后潜意识清零，不主动回看 TodoWrite。

## 纠正
已写入 ops/rules/会话收尾检查.md：每次子任务完成后强制回看全局清单。
