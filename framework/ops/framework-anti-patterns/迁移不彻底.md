# 迁移不彻底

> 反模式 = 踩过的坑。

## 发生了什么

知识库从 V2.x `wiki/`（→ 现 ops/ + knowledge/）扁平结构迁移到 V4.x `ops/` + `knowledge/` 四层架构后，目录改名/移动完成，但文件内容中 ~90 处 `ops/rules/`、`wiki/anti-patterns/`、`wiki/patterns/` 引用未同步更新。skill 降级路径全部断裂（P0），规则文件中的自引用路径全部失效。

## 根因

- 迁移时只改了目录名，没扫文件内容
- 没有全量 grep 检查旧路径残留
- 没有自动化路径替换脚本（现在有了 kb-do.sh rename）
- 审计滞后：V4.2.0 运行多日才发现

## 怎么修的

7 Phase 批量修复——Phase 1-2 路径归一化（~36 文件），Phase 7 四路验证确认零残留。

## 怎么防

- 任何目录改名/移动后，立即 `grep -r "旧路径"` 全量扫描
- 使用 `kb-do.sh rename` 原子操作（自动替换引用）
- 双报告交叉验证：Template 审计 + 实际库审计互查
