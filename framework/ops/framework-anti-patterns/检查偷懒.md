# 检查偷懒：ls 替代 find

## 反模式
用 `ls` 查看 `raw/inbox/` 或 `.inbox/` 根目录，未递归搜索子文件夹，遗漏用户放入子目录的待处理文件。

## 正确做法
使用 `find personal/data/inbox -type f` 递归检查所有子目录。inbox 设计本身就支持子目录结构。
