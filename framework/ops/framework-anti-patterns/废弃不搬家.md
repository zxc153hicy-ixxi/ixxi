# 废弃不搬家

文件 status 改为 deprecated 后仍留在活跃目录（ops/rules/、ops/anti-patterns/），导致文件计数不准确、目录混乱。

## 根因
- 状态和物理位置脱钩
- 没有联动规则

## 修复
- 知识库运维规范新增「废弃联动」规则：改 status→deprecated 时提示移至 archive/
- 批量清理 4 个已废弃文件的物理位置
