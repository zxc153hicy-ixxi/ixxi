# 产出计划未登记待办

## 触发场景
完成 ixxi 实施计划（设计阶段收尾产出）后，只把计划文档写进了 designs/ 并登记到 index.md，但没有把「执行实施计划」这个动作登记进 queue.md。用户新开会话想执行实施时，G8 启动加载第 4 步查 queue.md 看到「（空）」，识别不到「有实施任务待执行」，任务接力断裂，靠用户手动发现才补上。

## 根因
完成「计划 / 设计类」产出后，只关注「产出本身」（文档写好、登记进导航），漏掉了「接力」环节——把「下一步动作」（执行这个计划）登记进待办队列（queue.md）。G8 的待办识别依赖 queue.md，而 queue.md 没被更新，新会话自然识别不到。

## 纠正
完成任何「计划 / 实施计划 / 设计」类产出后，除了登记文档到 personal/index.md，还必须同步把「执行这个计划」登记为 personal/data/queue.md 待办（含入口、起点、执行方式），让新会话 G8 加载能识别到接力任务。原则：**产出「计划」≠ 登记「待办」，两者必须成对完成。**
