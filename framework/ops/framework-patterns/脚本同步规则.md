# 脚本同步规则

## 做法
修改规则/约定后，按清单逐个检查受影响的脚本，并跑验证：

1. 修改规则前，先列出所有依赖该规则的脚本
2. 修改后逐个检查，清理失效逻辑（死代码）
3. 跑验证确认脚本仍可用

## 为什么有效
- 规则一变，依赖它的脚本容易留下死代码（旧分支永远不触发）
- 按表检查 + 跑验证，把"应该同步"变成"必须同步"
