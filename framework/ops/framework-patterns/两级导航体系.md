# 两级导航体系

## 问题
知识库初期使用单一全局索引作为 MOC，直接链接 100+ 个文件。结果：
- 关系图谱呈星型拓扑（一个中心节点 + N 个孤立叶子）
- 浏览时需要在超长列表中翻找
- 同一目录下的文件缺少聚合入口

## 做法
每个主目录配一个中文描述名的索引页，形成两级结构：

```
全局索引（MOC）
  ├── 反模式索引
  ├── 正模式索引
  ├── 迭代记录索引
  ├── 查询报告索引
  ├── 归档内容索引
  └── 会话摘要索引
```

每个索引页包含：
- 目录内所有文件列表
- 每个文件的一句话描述
- 指向相关索引页的交叉引用

## 效果
- 全局索引从 100+ 行缩减到 ~80 行
- 关系图谱从单层星型变为两级树型
- 每个目录有独立入口，可独立浏览
- 索引页本身有描述名，看文件名即知内容

## 复用条件
- 目录内文件数 >10 时考虑建索引页
- 索引页命名 = 目录名 + 描述（如 `反模式索引`、`创作内容索引`）
- 全局索引只链接索引页 + 高频文件，不逐条列出
