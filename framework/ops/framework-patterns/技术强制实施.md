# 技术强制实施

## 做法
需要长期执行的保障措施，用技术手段强制实施，而不是靠人记、靠提醒。本案例共 8 项措施全部落地：pre-commit hook + 4 个检查脚本 + 敏感扫描 + 审计。8/8 测试通过。

## 为什么有效
- 人的记忆会漂移，脚本不会——把"每次都要做"变成"不做就失败"
- 强制在提交/运行前执行，把问题拦截在入口
- 实施后有测试验证，确保措施本身可用

## 原则
- 能写脚本强制的，不靠人记（先技术，后提醒）
- 措施实施后必须测试验证，防止"装了但没生效"
