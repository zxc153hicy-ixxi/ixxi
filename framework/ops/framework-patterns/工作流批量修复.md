# 工作流批量修复

## 场景
批量操作 >10 项时，编写 Workflow 脚本分 Phase 并行，每 Phase 修完即验。

## 效果
手动需 2-3 小时的操作压到 22 分钟，问题可精确定位到单个 Agent。

## 复用条件
- 批量操作 >10 项
- 每项操作可独立执行
- 有明确的验证标准
