# 统一版本号管理

系统唯一版本源 = 版本元数据文件（如 AGENT.md/项目元数据）。设计方案、git tag、模板全部跟随，用自动检测脚本检测不一致。

## 核心原则
- 标准 semver（主.次.修订），不以十进一
- 主版本：架构变更或新机制上线
- 次版本：重要修复或顶层规则新增
- 修订号：小优化、格式修正
- 所有出现版本号的位置都跟随唯一版本源，不各自维护

## 为什么有效
- 版本号分散多处，人工同步必然漂移；单一版本源 + 自动检测把漂移变成不可能
- semver 语义化让版本号传达变更范围，读版本号即可判断改动大小
