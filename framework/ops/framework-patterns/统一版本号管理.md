# 统一版本号管理

知识库唯一版本源 = AGENT.md。设计方案、git tag、模板全部跟随，用 check-version-sync.sh 自动检测不一致。

## 核心原则
- 标准 semver（主.次.修订），不以十进一
- 主版本：架构变更或新机制上线
- 次版本：重要修复或 G 层新增
- 修订号：小优化、格式修正
