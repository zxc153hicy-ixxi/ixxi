# 画像驱动行为

将沟通偏好（大白话比例、学习模式、术语来源等）写入 profile.md，G8 启动加载后自动生效，无需每次对话重复说明。

## 核心原则
- 偏好写入画像 → 自动加载 → 行为自动对齐
- 画像字段需定期验证（last-verified 不超过 90 天）
- 新增偏好先对话确认，确认后写入
