# 半自动化置信度分级

## 场景
设计非破坏性/破坏性操作边界：高置信度操作自动执行，破坏性操作必须确认。用置信度分级决定"哪些可以自动化、哪些必须人工确认"。

## 效果
- 大部分日常操作不再阻塞
- 破坏性操作保护不缩水
- 硬隔离清单防边界漂移
- 复用已有置信度框架，不引入新概念

## 复用条件
- 有明显的高/低风险边界
- 有可写死的操作清单
- 与现有约束不冲突
