# 半自动化置信度分级

## 场景
设计非破坏性/破坏性操作边界，high confidence 自动执行，破坏性操作必须确认。

## 效果
- 70% 日常操作不再阻塞
- 破坏性操作保护不缩水
- 硬隔离清单防边界漂移
- 复用已有置信度框架，不引入新概念

## 复用条件
- 有明显的高/低风险边界
- 有可写死的操作清单
- 与现有 G 层约束不冲突
