# 转换前预扫描

## 做法

任何文档入站 → 先跑预扫描脚本采样 → 自动判断格式类型 → 推荐最佳工具 + 预估耗时 + 可执行命令 → 直接转换。

## 为什么有效

- 408 页文字型 PDF 用重型 OCR 工具跑 1.5 小时 vs 轻量解析秒级，差异百倍
- 预扫描自动采样 7 页判断文字/扫描类型，准确率高于人工猜测
- 输出包含预估耗时，用户可以决定是否值得等

## 适用场景

- PDF/DOCX/PPTX/XLSX/EPUB/MOBI/HTML/图片/音频 → Markdown 转换
- 尤其 PDF：必须采样判断文字型还是扫描件
- 批量转换前对样本文件做预判

## 核心原则

- 不预扫描直接盲转 = 开盲盒，可能为不需要的格式付出百倍时间
- 用采样预判替代人工猜测，用预估耗时让用户提前决策
