# 反馈不完整

只记差评不记好评，被动等评价。

## 反模式
反馈收集回路只采集负面反馈，忽略正面反馈；并且被动等待用户主动给出评价，不主动收集。

## 为什么是问题
- 只记差评会系统性地偏斜判断：无法区分「哪些做法是被验证有效的」与「哪些只是没被骂过」。
- 被动等评价会漏掉大部分反馈——用户很少主动夸奖，但不代表没有可学的东西。
- 没有完整反馈，就无法校准行为、也无法沉淀可复用的正模式。

## 正确做法
1. 反馈采集必须**同时覆盖正、反两面**：好评（验证有效、可复用）与差评（纠正、反模式）同样重要。
2. **主动收集**而非被动等待：关键节点主动询问，而非等用户自己说出来。
3. 正面反馈用于沉淀可复用的做法，负面反馈用于沉淀反模式，两者配套才完整。
