# 解析器过度简化

写自定义解析器时只覆盖了最简单的输入格式，未考虑实际数据中的嵌套结构。本例中自定义 YAML 解析器的初始版无法解析列表（`- item`）和嵌套字典（`key: {sub: val}`），而配置文件恰好依赖这两种结构。

## 根因

写解析器时脑子里只有"简单键值对"场景，没有遍历实际配置数据验证。代码先于测试。

## 教训

1. 解析器写完第一步：用实际数据验证，不是用想象中的简化数据
2. 覆盖所有目标格式中的结构——列表、嵌套、引号、注释
3. 如果不愿处理复杂结构，应切换到成熟库（如 PyYAML）而非坚持手写

## 修正

手写解析器重写为 while + lookahead（前向探测）模式，逐一覆盖列表与嵌套结构。
