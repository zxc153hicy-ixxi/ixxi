# 工具链自修复

## 场景

自动化脚本依赖外部 CLI 工具（如 `markitdown`、`pandoc`），但环境中 CLI 未加入 PATH，导致批量操作全部失败。

## 做法

1. 脚本启动时检查 CLI 可用性（`shutil.which()`）
2. CLI 不可用时，检测是否有等效 Python API（`try: from module import Class`）
3. 有 API → 自动降级走 API，标注 `"tool_name": "MarkItDown (API)"` 记录实际路径
4. 无 API → 报告明确错误（`pip install xxx` 安装指引）
5. 降级逻辑内聚在脚本中，调用方无感

## 为什么有效

- **消除手动绕过**：不用每次 `python batch_convert.py` 临时写新脚本
- **单点修复全局生效**：修一次 `auto-import.py`，所有后续导入自动受益
- **可追溯**：转换结果中标记实际工具路径，出问题可回溯

## 实例

`auto-import.py` 中 MarkItDown 的 CLI→API 降级：

```python
_MARKITDOWN_CLI = shutil.which("markitdown")

if info["tool_name"] == "MarkItDown" and not _MARKITDOWN_CLI:
    success, stdout, stderr = _markitdown_api_convert(filepath, output_file)
```
