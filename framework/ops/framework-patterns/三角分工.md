# 三角分工

知识库三大扩展系统各管一摊，互不重叠：

| 系统 | 管什么 | 谁干活 |
|------|------|------|
| skill | 操作手册 | LLM 读了照做 |
| hook | 机械步骤 | 机器自动跑 |
| agent | 多视角审查 | 独立小模型看 |

## 核心原则
- 一件事只由一个系统管
- 新增操作先判断是哪种类型，再决定用哪个系统
- curator 管各自的生命周期，共享统一的阶段判断
