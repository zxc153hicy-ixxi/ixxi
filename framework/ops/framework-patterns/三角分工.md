# 三角分工

框架三大扩展系统各管一摊，互不重叠：

| 系统 | 管什么 | 谁干活 |
|------|------|------|
| skill | 操作手册 | LLM 读了照做 |
| hook | 机械步骤 | 机器自动跑 |
| agent | 多视角审查 | 独立小模型看 |

## 核心原则
- 一件事只由一个系统管，职责不重叠、不冗余
- 新增操作先判断是哪种类型，再决定用哪个系统
- 各子系统由统一的调度器管理生命周期，共享同一套阶段判断，避免口径分裂

## 判断要点
- 需要判断/理解的操作 → skill（供 LLM 参考执行）
- 纯机械、确定性步骤 → hook（交给机器自动跑）
- 需要独立视角挑错 → agent（独立小模型审查）
