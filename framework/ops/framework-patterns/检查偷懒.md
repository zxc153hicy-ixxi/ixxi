# 检查偷懒：ls 替代递归搜索

## 反模式
用 `ls` 查看入站/收件目录根目录，未递归搜索子文件夹，遗漏用户放入子目录的待处理文件。

## 正确做法
使用 `find <dir> -type f` 递归检查所有子目录。设计支持子目录结构的目录，只看根目录必然漏文件。

## 通用启示
- 排查目录内容时，**默认递归**，除非明确知道目标目录是扁平结构。
- 递归检查的代价远低于"遗漏文件后返工"的代价。
- 检查类的操作也要防"检查自身偷懒"——用最省力的方式（只看根目录）最容易自我感觉良好而漏检。
