# 分类前告知方案与后果

## 模式
涉及文件结构变更时，不直接动手，先展示：
1. 当前状态
2. 建议方案
3. 优劣对比
4. 后果评估（无数据丢失、链接断裂风险等）

用户确认后再执行。用户要求：以后每次分类前都需要这样做。
