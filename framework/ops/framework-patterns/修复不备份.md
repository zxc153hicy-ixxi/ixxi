# 修复不备份

## 发生了什么

一次架构修复过程中：删除归档目录 → 删除多个技能副本 → 移动外部技能目录 → 覆盖配置文件。全部未做任何事前备份。

## 根因

1. 版本控制系统提供了"事后回滚"的安全感，诱使跳过事前备份
2. 修改确认流程已满足（用户口头确认"执行吧"），但备份步骤不属于确认流程的一部分
3. 备份函数存在但未被调用——工具建成但未强制使用
4. 有上次修复的备份先例，但本次没有参考

## 怎么修

1. 破坏性批量操作前必须执行备份函数（如 `git_backup "<操作名>"`）
2. 自动修复类命令内置自动备份逻辑
3. 将备份步骤写入修改确认流程：确认 → 备份 → 执行
