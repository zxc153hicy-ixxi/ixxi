# 口头未来做不落地

## 发生了什么

会话里反复出现「以后丰富引导再切 sync 生成」「install 后升级要重装」这类口头承诺，说完就散在对话里，没有落地成「会被主动提醒的待办项」。LLM 不主动翻回去看，用户也只能靠「突然想起来」——而想起来的时候很少。结果一堆「未来做」变成了「永远不会做」。

## 根因

「未来做」的承诺，本质是「待办项」，但没有一个「当场登记 + 会被主动检查」的机制，导致它停留在「口头」层面。双方都默认「以后会想起来」，但没有任何东西会在「以后」主动提醒。

## 纠正

- 建立唯一 backlog（如未落地清单），凡「以后 / 未来 / 待 X 时」的承诺，**当场登记**，禁止只说一句就完事
- 让 backlog 在「加载 / 会话收尾」时被主动汇报（「当前待办 N 项」），让遗忘从「大概率」降到「每次都撞见」
- 立一条契约（如 G21 待办必登记），治 LLM「说完就丢」
