# 钩子只做纯机械

钩子系统设计原则：只做纯机械操作（数文件、比字符串、检测模式），需要语义判断的留给 LLM 做。

## 核心原则
- 机械操作 → hook（100%准确，零token）
- 语义判断 → LLM（需要理解上下文）
- 不确定的就不要自动化

## 反例
counter-inc.sh——试图用 hook 自动判断当前是什么操作（ingest还是lint），但 hook 只能看到工具名（Write/Edit），不知道 LLM 在执行什么任务。最终移除，计数器仍由 LLM 手动更新。
