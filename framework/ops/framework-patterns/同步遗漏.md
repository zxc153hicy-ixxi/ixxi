# 同步遗漏

## 场景

修改系统文件（代理配置文件、规则文件、脚本）或写入新文件后，忘记同步更新下游产物。同一根因在不同产物上反复出现：

| 实例 | 触发 | 遗漏项 |
|---|---|---|
| 设计同步遗漏 | 新增结束检查规则 | 未同步设计方案文档 |
| 模板同步提醒遗漏 | 流程规则新建 | 未提醒导出模板 |
| 方案同步遗漏 | 代理配置文件修改 | 未同步备选方案 |
| 第 5 次忘同步 | 同一会话第 5 次 | 模板 + 设计方案双重遗漏 |
| 写文件不更新索引 | 写入记录文件 | 漏更新索引页，38% 遗漏率 |

## 根因

新建规则/机制后未形成习惯回路——行为没有和触发条件绑定。检查脚本都在但提醒动作未被技术强制。

## 纠正

- 会话结束检查会强制提醒同步
- 流程规范覆盖「设计与实现同步」+「模板同步」+「脚本同步」三重
- 规则变更 → 按表检查受影响脚本 → 跑验证
- 索引场景：技术强制「写文件必须更新索引」（索引覆盖检测护栏）
