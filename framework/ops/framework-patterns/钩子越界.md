# 钩子越界

让自动化钩子去做需要语义判断的事——比如自动判断当前是什么操作并更新对应计数器。

## 根因
- 钩子只能拿到工具名（Write/Edit/Bash），不知道执行者正在做什么任务
- 把需要理解上下文的事交给机器，结果不可靠

## 修复
- 移除让钩子做语义判断的脚本
- 语义类更新（计数器、归属判断）仍由执行者按规则手动完成
- 钩子系统设计原则：**只做纯机械，不碰语义判断**

## 通用启示
- 自动化的边界在于「无需上下文、输入输出确定」的纯机械操作；凡需要理解「正在做什么、为什么」的操作，都不该塞进钩子。
- 判断「什么属于纯机械」时，以钩子实际拿到的信息量为准——它只看到触发信号，看不到意图。
