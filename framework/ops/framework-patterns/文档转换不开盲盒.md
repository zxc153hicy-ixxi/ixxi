# 文档转换不开盲盒

## 现象

用户给出 PDF → 直接调用重型转换工具 → 408 页纯文字型 PDF 跑了 1.5 小时。

## 后果

- 纯文字型 PDF 用轻量工具（Pandoc/MarkItDown）秒级完成，重型工具慢百倍
- 首次运行还触发上 GB 模型下载，额外等待数分钟
- Token 浪费严重——不停读后台进度条输出

## 正确做法

先用预扫描脚本采样判断文档类型，输出推荐工具后再转换。
