# 废弃不搬家

文件状态标记为 deprecated（废弃）后仍留在活跃目录，导致文件计数不准确、目录混乱。

## 根因
- 状态和物理位置脱钩：元数据改了，物理位置没动
- 没有联动规则：改状态时不触发物理迁移

## 修复
- 运维规范新增「废弃联动」规则：改状态为废弃时提示移至归档目录
- 批量清理已废弃文件的物理位置

## 通用启示
- 「状态」与「物理位置」应保持一致：一个对象被标记废弃/停用，就应离开活跃区域，否则所有按目录的统计、扫描、遍历都会被污染。
- 状态变更应联动位置迁移，把「搬家」编进状态变更流程本身，而非靠人记。
