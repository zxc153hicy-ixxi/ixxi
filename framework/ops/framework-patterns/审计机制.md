# 审计机制

周期性全量审计，逐项检查规则覆盖情况，找出日常增量维护发现不了的遗漏与漂移。

## 核心原则
- 全量审计不是抽查：逐项核对规则/机制是否全覆盖，不让「看起来覆盖了」蒙混过关
- 重点发现两类问题：
  - 路由层遗漏——某些场景没有对应的规则或入口
  - 顶层规则与细则文件漂移——上层原则改了，下层文件没跟上
- 审计发现的问题输出清单，按优先级补齐

## 为什么有效
- 增量维护只覆盖「最近碰过」的地方，全量审计兜住长期积累的盲区
- 规则体系随时间膨胀，没有定期全量核对就会在不知情中腐烂
