# 测试清理系统

## 做法
用清单文件（manifest）显式标记所有测试产物，统一清理：

1. 测试创建的文件写入 `.test-manifest` 清单
2. 清理时按清单自动删除，不依赖"猜哪些是测试残留"
3. 删除后清空清单，并再次扫描确认无残留

## 为什么有效
- 清理目标由清单显式定义，避免误删真实文件、也避免漏删残留
- 删除后二次扫描作为验证闭环，防止"清了但没清干净"
- 清单机制可复用：任何需要"可控产生 + 可控清理"的场景
