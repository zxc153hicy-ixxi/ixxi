# 统一扩展目录

所有框架扩展系统（技能/钩子/agent/MCP）统一放在一个根目录下，每个子系统有自己的调度器和注册表文件。入口注册表中一张扩展系统路由表管理全部入口。

## 核心原则
- 一个目录入口：扩展系统根目录
- 每个子系统独立目录 + 注册表 + 调度器
- 入口注册表的路由表统一索引
- 新增系统只需加目录 + 注册 + 更新一行路由

## 为什么有效
- 扩展系统散落各处会失控；单一入口让「加一个扩展」变成标准化三步
- 每个子系统独立调度器 + 统一路由表，既自治又可被全局索引
- 路由表一张表看全所有扩展入口，维护成本随系统增长保持线性
