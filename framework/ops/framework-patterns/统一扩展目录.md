# 统一扩展目录

所有知识库扩展系统（技能/钩子/agent/MCP）统一放在 `framework/core/` 下，每个子系统有自己的 curator 和 registry.json。AGENT.md 中一张扩展系统路由表管理全部入口。

## 核心原则
- 一个目录入口：`framework/core/`
- 每个子系统独立目录 + registry.json + curator
- AGENT.md 路由表统一索引
- 新增系统只需加目录 + 注册 + 更新一行路由

## 关联
- framework/ops/rules/技能化流程 —— curator 统一管理
- `framework/core/` —— 扩展系统目录
