# 生成与验证分账

## 场景

做了某个功能或适配，但当前环境无法实测——比如只有 Claude Code 环境，测不了 Codex 的 `.codex/agents/*.toml`、Hermes 的命令索引。

## 正确做法

1. **生成做完整**：把「能做的」（生成产物）做到位，不因「无法实测」就跳过——设计要做、计划里有，就生成完整
2. **验证留待环境**：实测等环境具备后做，产物明确标记「待验证」
3. **诚实分账**：区分「生成完成」和「验证通过」，不把生成冒充验证（对应不变量 I4 声明 == 实际）

## 反例

因为「无法实测」就跳过生成，导致产物缺失——ixxi 的 Codex agent 适配（`.codex/agents/*.toml`）就曾因此是 0 个（sync 脚本有，但源库从没跑过）。
