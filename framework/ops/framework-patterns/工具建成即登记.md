# 工具建成即登记

> 正模式 = 验证有效的做法：写完工具脚本后，必须在工具导航中登记入口。

## 是什么

新建或合并工具脚本后，立即更新登记：
1. **工具清单** — 更新脚本数量和名称列表
2. **导航入口** — 在工具区域添加入口链接

## 为什么有效

- **反模式教训**：本案例中合并了 3 个脚本，建完就跑通验证，但忘记登记。结果工具清单仍写着旧数量，实际已有 15 个。"工具优先"要求机械操作前先查现成工具，但工具不可发现等于不存在。
- **闭环**：工具优先不只是写脚本，还包括让后续 Agent 能找到脚本。登记是实现可发现性的最后一步。

## 什么时候用

| 触发条件 | 动作 |
|------|------|
| 新建脚本 | 更新工具清单计数 + 导航入口 |
| 合并/删除脚本 | 同步更新清单的计数和列表 |
| 体检检测到脚本碎片化 | 合并后走本流程登记 |

## 登记清单

- [ ] 工具清单：更新脚本数量和分类
- [ ] 导航入口：新增入口（至少列出高频脚本）
- [ ] 检查体系附录：脚本总览表同步
- [ ] 命令翻译表：如有命令链变化需同步
