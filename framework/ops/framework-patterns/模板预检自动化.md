# 模板预检自动化

导出模板前执行预检脚本，不过检不导出。

## 检查维度
- 泄露检测（全目录覆盖+非.md扫描）
- 完整性（系统文件逐项核对）
- YAML格式（必填字段校验）
- 结构文件完整性

## 核心原则
- 导出/发布前先跑自动化预检，把「漏了检查项」变成不可能
- 预检覆盖四类问题：敏感信息泄露、文件缺失、格式非法、结构损坏
- 预检脚本化后每个导出动作自动执行，不依赖人工记得逐项核对
