# 交叉验证审计

## 模式

对知识库做深度审计时，采用双份独立审查交叉验证：

1. **两份独立审查**：不同视角（模板消费者 vs 实际运行库）、不同审计者（外部报告 + LLM 自审），或两个独立 AI（不共享上下文、不同提示词、不同方法论偏好）
2. **重叠项**：两报告一致发现 → 高置信，无需二次确认，直接入修复队列
3. **独有项**：各报告单独发现 → 揭示对方盲区，互补覆盖
4. **合并去重**：输出完整问题清单，标注每项来源（A独有/B独有/重叠）

## 两种具体形式

- **双报告交叉**：两份独立报告（Template 审计 + 实际库审计）交叉验证
- **双 AI 交叉**：两个独立 AI（如 Claude + 智谱）各自审查，第三方交叉对比

## 效果

- Template 审计（26）+ 实际库审计（64）→ 合并去重 → 78 个独立问题，重叠 12 项直接入 P0-P1
- 双 AI：Claude 审出 17 项、智谱审出 13 项，交叉后 P0 从 1 项（单视角）→ 7 项（双视角）

## 适用条件

- 系统复杂度 ≥ 100 文件
- 审查覆盖面 ≥ 3 维度
- 两个审查者方法论有明显差异
