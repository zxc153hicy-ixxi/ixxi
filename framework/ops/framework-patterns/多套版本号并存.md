# 多套版本号并存

规范文档、设计方案、版本标签（git tag）各自有不同版本号，导致无法判断哪个才是权威版本，后续同步容易出错。

## 根因
- 设计方案单独升级，规范文档未同步
- 没有自动检测机制

## 修复
- 统一为唯一版本源（权威文档）
- 自动比对脚本定期检查各处的版本号是否一致

## 通用启示
- 任何被多份文档/产物引用的"版本"都必须有**唯一权威源**，其余位置只引用该源。
- 单一来源仍不够——必须有自动检测，否则「该同步但没人发现不同步」会长期潜伏。
