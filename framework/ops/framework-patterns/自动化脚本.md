# 自动化脚本

少量脚本覆盖多项重复机械操作（如数据检查、统计、收尾处理），把高频人工命令收敛成脚本调用。

## 核心原则
- 识别反复出现的机械操作序列，收敛为脚本，一次封装反复受益
- 脚本按职责划分：检查类（数据校验/完整性）、统计类（计数/汇总）、收尾类（清理/完成处理）
- 每个脚本只做一件事，可组合调用

## 为什么有效
- 手动命令越多越容易出错、越浪费时间；脚本化后每次操作省下一串命令
- 重复机械步骤交给脚本，人工专注需要判断的部分
