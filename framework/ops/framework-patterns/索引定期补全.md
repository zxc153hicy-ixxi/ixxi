# 索引定期补全

## 做法

每次内容入库流程或定期维护时，对比目录实际文件列表与索引页条目，找出遗漏项并补全。

## 为什么有效

- 人类/LLM 写完文件后容易忘记更新索引，目录扫描能兜底
- 实际案例：一次对比发现约 38% 的文件未入索引，纯靠人工记得更新不可靠
- 脚本化对比后批量补全比逐个手动快得多

## 什么时候用

- 每次内容入库流程中更新索引步骤时自动执行
- 索引一致性检查中作为必查项
- 发现索引条目数与目录文件数不一致时触发

## 核心原则

- 目录是事实源，索引是视图——以目录为准找出遗漏
- 把「对比+补全」脚本化，让索引完整性不依赖记忆
