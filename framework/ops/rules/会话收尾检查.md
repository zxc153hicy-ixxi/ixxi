# 会话收尾检查

## 约束

1. 每次完成一个子任务后，必须回看 TodoWrite 全局清单
2. 确认「还有未完成项 → 主动提醒用户 → 等确认是否继续」
3. 确认「全部完成 → 检查收尾三件套（git commit / 污染清理 / 会话入库）」
4. 禁止完成当前步骤后直接汇报「完成」而不检查全局清单

## 正例

> P0 修复完成 → 回看清单：「P0 全部通过，但还有 11 项 P1 待修。继续还是先标记？」→ 等人决定

## 反例

> 工作流修完 28 项 → 直接汇报「全部通过」→ 忘了 git commit → 用户追问才发现没收尾

## 例外

### 例外1：用户打断
- 触发条件：用户在子任务中途下达新指令
- 例外行为：先响应当前指令，完成后回看清单
- 标志动作：回复中标注 `[清单待查]`
