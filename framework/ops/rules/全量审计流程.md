# 全量审计流程

## 约束

1. `/audit` 扫描 personal/data/ 与 personal/raw/ 下所有文件 → 对照 queue.md → 列出未入队的文件
2. 标注类型：高→自动标记为 `[x]`（标注原因），中→自动入队为 `[ ]`（待后续Ingest），低→仅列出供人工确认
3. 新机制上线时必须执行一次存量回溯
4. 审计结果输出到 `personal/knowledge/projects/知识库管理/queries/audit-report-YYYY-MM-DD.md`

## 正例

> 新机制上线 → 增量自动跟踪 → 对存量跑 `/audit` → 发现 8 条遗漏 → 全部补标记 → 机制生效

## 反例

> 建了 queue 机制但只管增量 → 存量 sessions 从未回溯 → 机制不完整

## 例外

### 例外1：仅报告模式
- 触发条件：`/audit --dry-run`
- 例外行为：仅输出遗漏清单，不修改任何文件
- 标志动作：标注 `[dry-run]`
