# 命名规范

## 一、文件命名

### 约束

1. **望文知义**——看到文件名就能知道大致内容，无需打开正文
2. **中文直连**——中文语义段之间不加分隔符：`反馈闭环流程.md`
3. **英文 kebab**——英文语义段之间用 `-`（连字符）：`session-notes.md`
4. **中英混合用 `-` 连接**——`ixxi-agent-产品分析报告.md`
5. **版本后缀用全角括号**——`源质挽歌设定（第十一版）.md`，不用半角 `(V2)` 或下划线 `_V2`
6. **日期不进文件名**——放 frontmatter 的 `created` 字段
7. **同目录文件名必须唯一**——去分隔符后冲突时人工裁决

### 正例

```
反馈闭环流程.md                          # 中文直连，望文知义
session-notes.md                         # 英文 kebab
ixxi-agent-产品分析报告.md                 # 中英混合，- 连接
源质挽歌设定（第十一版）.md                # 版本后缀，全角括号
README.md                                # 标准索引名
```

### 反例

```
# 错误：看文件名不知道是什么
activation.md              → 目录激活清单.md

# 错误：中文加了分隔符
反馈_闭环_流程.md           → 反馈闭环流程.md
反馈-闭环-流程.md           → 反馈闭环流程.md

# 错误：空格
源质挽歌 设定（第十一版）.md  → 源质挽歌设定（第十一版）.md

# 错误：半角括号
源质挽歌设定(V2).md         → 源质挽歌设定（V2）.md

# 错误：日期塞在文件名里
2026-07-12-知识库全量优化.md → 知识库全量优化.md（日期放 created）

# 错误：中英连接用了下划线
ixxi_agent_产品分析报告.md   → ixxi-agent-产品分析报告.md
```

## 二、Frontmatter 元数据

适用于所有需要版本管理的 `.md` 文件。

### version_of（版本链标识符）

8. **必须使用人类可读的中文全称**，禁止缩写或代号
9. **同一版本链的所有文件必须用完全相同的值**（包括标点、空格）
10. **禁止含版本号**——version_of 是"什么东西的版本"，不是"哪个版本"
11. **新链取值**——取最新版文件名去掉版本后缀部分。如 `源质挽歌设定（第十一版）.md` → `version_of: "源质挽歌设定"`

### version（版本号）

12. **必须使用以下四种格式之一**：

| 格式 | 示例 | 适用场景 |
|------|------|------|
| 纯数字 | `"11"`、`"7"` | 线性迭代（如小说设定第七版→第十一版） |
| 两段式 | `"2.1"`、`"2.15"` | 主版本.次版本（如方案迭代） |
| 语义版本 | `"0.6.1"` | 软件项目迭代 |
| 数字-标签 | `"8-整合修订"`、`"1-草案"` | 同主版本的不同修订变体 |

13. **同一 version_of 下用同一格式**，禁止混用
14. **引号包裹**——YAML 字符串，避免 `"1.10"` 被解析为浮点数
15. **文件名与 frontmatter 版本语义一致**——`源质挽歌设定（第十一版）.md` 的 `version` 必须是 `"11"`，不能是 `"10"` 或其他值

### status（辅助字段）

16. 已被取代的旧版文件标注 `status: archived`

### 正例

```yaml
# 线性版本
---
version: "11"
version_of: "源质挽歌设定"
---

# 语义版本
---
version: "0.6.1"
version_of: "ixxi-agent"
---

# 修订变体
---
version: "8-整合修订"
version_of: "源质挽歌设定"
status: archived
---
```

### 反例

```yaml
# 错误：version_of 用缩写
version_of: "源质"              # → "源质挽歌设定"

# 错误：version_of 含版本号
version_of: "源质挽歌V11"        # → "源质挽歌设定"

# 错误：格式不支持
version: "最终版"                # 无法排序
version: "v2.1-gtri"            # 会被 SKIP

# 错误：同一链混用格式
version: "11"                   # 源质挽歌设定链内不能同时有纯数字和语义版本
version: "0.11.0"

# 错误：文件名与 frontmatter 不一致
# 源质挽歌设定（第十一版）.md → version 必须是 "11"
```

### 现有版本链注册表

| version_of | 格式 | 说明 |
|------|:---:|------|
| `源质挽歌设定` | 纯数字 + 数字-标签 | 第七版→第十一版，第八版有三个子变体 |
| `ixxi-agent` | 语义版本 | v0.3.0→v0.6.1 |
| `知识库方案` | 两段式 | v2.1→v2.15 |
| `武器种族舰船设定卷` | 数字-标签 + 纯数字 | V1草案→V2 |
