# 应急预案格式

## 约束

1. 应急预案必须包含：故障现象→排查步骤→解决方案→预防措施 四段
2. 排查步骤使用有序列表，每步以动词开头
3. 涉及命令时标注执行环境（如 `# Windows PowerShell`）
4. 方案必须可独立执行，不依赖外部上下文
5. 必须标注最后更新日期和验证状态

## 正例

> 「故障：X 无法启动」→「排查：1. 检查 Y 2. 查看 Z 日志」→「解决：修改配置 A」→「预防：添加监控 B」

## 反例

> 「遇到 X 问题就改配置」——缺少排查步骤和预防措施，无法复现时无从下手
> 命令不标环境，Linux 和 Windows 用户看到同一段指令

## 例外

### 例外1：快速修复
- 触发条件：故障原因明确、修复操作单步完成
- 例外行为：可省略排查步骤，直接给解决方案
- 标志动作：标注 `[快速修复]`
