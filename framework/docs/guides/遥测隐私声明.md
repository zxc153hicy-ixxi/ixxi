# 遥测隐私声明

> 对应不变量 **I8**（Telemetry 是决策信号，不是价值事实）+ 盲区 P1-6（遥测无隐私边界声明）。

## 一句话

ixxi 的遥测（`skill-usage.json`）**只存你的 personal 本地目录，绝不进 framework、绝不进贡献包、绝不上传**。

## 遥测是什么

| 项 | 内容 |
|---|---|
| 文件 | `personal/raw/sessions/skill-usage.json` |
| 记录什么 | 每个 capability 的 `count`（使用次数）、`first_seen`（首次使用）、`last_seen`（最近使用） |
| 谁写 | `record-usage.py`（kb-curator 在 skill 执行后自动调用） |
| 用途 | 演化决策信号——输出「N 天未触发」清单，供人工裁决保留/归档 |

## 隐私边界（四条硬约束）

1. **只存本地**：遥测写入 personal 实例层，`.gitignore` 排除，不进 framework 开源层。
2. **不进贡献包**：向 framework 贡献内容时，贡献包不含任何遥测数据。
3. **不含内容**：遥测只记「用了哪个 skill、用了多少次」，不记你的笔记正文、不记你的对话内容。
4. **可随时删除**：删除 `personal/raw/sessions/skill-usage.json` 即可；`record-usage.py <name> --reset` 可重置单个。

## 为什么是「信号」不是「价值」（I8）

高频使用 ≠ 有价值，低频使用 ≠ 没价值。遥测只提供「这段时间哪些能力没人碰」的**候选信号**，最终保留/归档由**你人工裁决**。Critical capability（`lifecycle_class: critical`）更是**禁止仅凭 last_used 自动归档**（I9）。
