# 通用 Agent 架构参考

> 本文档是「双系统架构 + 三级决策制」的通用技术思想，剥离自一个 AI 写作 Agent 项目（架构规范 + 设计需求合并）。会话迭代记录、具体项目名、场景绑定内容不在此列（留原实例）。

## 核心定位

AI 协作 Agent。核心理念：**AI 帮你做，但不替你决定。** 用户在每一步都有决定权。

## 双系统架构

- **主系统（决策路由）**：负责决策路由、建议生成、用户交互。
- **工具箱（能力系统）**：具体能力是主系统的工具箱，可插拔替换。

该架构源自三类项目的技术融合：RAG 多索引、状态机 + 审校回路、结构化生成。

## 三级决策制

优先级自上而下，不可倒置：

| 优先级 | 决策主体 |
|:---:|------|
| 1 | 用户决定 |
| 2 | 规范约束 |
| 3 | AI 判断 |

## 架构决策记录

- 去掉本地模型，只使用 API 调用（降低部署复杂度与本地依赖）。
