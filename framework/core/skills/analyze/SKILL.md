# kb-analyze

## Overview
对提案进行五维加权可行性评分，输出评分卡和推荐决策。

## 五维评分锚

| 维度 | 说明 |
|------|------|
| 必要性 | 这个问题值得解决吗 |
| 技术难度 | 实现门槛多高 |
| 资源投入 | 要花多少时间/精力 |
| 风险 | 做砸了损失什么 |
| 收益 | 做成了得到什么 |

各维 1-5 分，总分取加权平均。

## 阈值

| 总分 | 决策 |
|------|------|
| ≥3.5 | 建议推进 |
| 2.5-3.5 | 需优化后重评 |
| <2.5 | 建议放弃 |

## 评分卡格式

```
| 维度 | 得分 | 依据 |
|------|:---:|------|
| 必要性 | X | 一句话 |
| 技术难度 | X | 一句话 |
| 资源投入 | X | 一句话 |
| 风险 | X | 一句话 |
| 收益 | X | 一句话 |

总分 X → 建议推进 / 优化后重评 / 放弃
关键风险（≥2）：...
替代方案（≥1）：...
```

## 硬闸门自检（不可跳过）

- 五维全评，缺一维不输出评分卡
- 关键风险 ≥2 条 + 缓解措施
- 替代方案 ≥1 条 + 对比
- 例外：用户说「不用打分，直接说结论」→ 跳过评分矩阵，但仍列关键风险
