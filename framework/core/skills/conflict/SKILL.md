# kb-conflict

## Overview
发现新知识和旧规则打架了？帮你标出来问题在哪，给你 5 个解决方案自己挑，不替你做决定。
技术说明：矛盾检测 → 分桶标注 → 暂停 Ingest → 输出《反馈冲突提示》→ 人类 5 选 1 裁决 → 校验兼容性。

## Quick Reference

### 矛盾类型
| 类型 | 判定 |
|------|------|
| 直接反对 | 新主张落在旧条目禁止清单内 |
| 范围冲突 | 新条目收窄旧条目适用范围 |
| 优先级冲突 | 同一场景互斥，无优先级 |

### 裁决选项
| # | 选项 | 操作 |
|:---:|------|------|
| 1 | 新取代旧 | 旧条目 deprecated |
| 2 | 新是例外 | 旧保留 active，追加例外段落 |
| 3 | 新不纳入 | 保留 personal/data/ 记录，log 记录 |
| 4 | 分场景生效 | 双方 active，限定 scene |
| 5 | 拿不准 | 进入五维可行性分析 |

### 置信度分级
| 置信度 | 行为 |
|------|------|
| 高 | 暂停 Ingest，等待裁决 |
| 中 | 不暂停，继续+变更摘要标注 |
| 低 | 不告警 |

## 冲突提示模板

输出《反馈冲突提示》，格式：

```
# 反馈冲突提示
- 矛盾类型：<直接反对 / 范围冲突 / 优先级冲突>
- 旧条目：<内容>
- 新主张：<内容>
- 冲突点：<一句话>
- 裁决选项：1 新取代旧 / 2 新是例外 / 3 新不纳入 / 4 分场景生效 / 5 拿不准
- 请选择：1-5
```

## 硬闸门
- **G3**：禁止自行裁决，必须等人类选择 1-5
- 待裁决 >5 条 → 暂停新 Ingest
- >45 天未裁决 → 默认执行选项 3（不纳入）
- 裁决后必须校验：新条目兼容性 + deprecated 悬空引用
