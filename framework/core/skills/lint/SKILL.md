# kb-lint

## Overview
给知识库做个全身检查，看看有没有小毛病（比如链接断了、格式乱了、内容过时了），检查完给你打个分。
技术说明：7 项日常 + 7 项深度共 14 项检查，输出健康度评分。

## Quick Reference

### 日常检查（7项，`/lint`）

| # | 检查项 | 修复方式 |
|:---:|------|------|
| 5 | 反模式触碰 | 人类裁决后修复 |
| 6 | CLAUDE.md 行数 | >180 输出精简建议 |
| 8 | YAML 格式校验 | 错误自动修复 |
| 9 | 链接密度 | <3 孤岛候选，>15 过密 |
| 10 | scene+domain 一致性 | 自动修复/告警确认 |
| 11 | draft 堆积 | >30天→告警 |
| 14 | 疑似重复 + **技能化候选** | 人类选择处理 |

### 深度检查（7项，`/lint --full`）

| # | 检查项 | 修复方式 |
|:---:|------|------|
| 1 | 页面矛盾 | 人类裁决 |
| 2 | deprecated 清理 | 仅告警 |
| 3 | 孤立页面 | 建议交叉引用 |
| 4 | 缺失交叉引用 | 建议→确认 |
| 7 | 隐性矛盾 | 人类裁决 |
| 12 | 内容过时 (>90天) | 输出《刷新建议》 |
| 13 | Git 健康 | 输出报告 |

## 输出模式
- `/lint` — 摘要模式（仅需行动项）
- `/lint --full` — 14 项完整检查
- `/lint --verbose` — 完整明细

## 系统健康度
```
健康度 = (自动化通过率 × 50) + ((1 - 反模式触碰率) × 50)
```
≥70 健康 | 50-70 预警 | <50 异常

## 阈值策略
冷启动前 5 次固定阈值，之后切换动态基线（近 5 次均值 ×1.5/×2.0）

## 硬闸门自检（不可跳过）

- 14 项检查不可省（7 日常 + 7 深度），`/lint` 摘要模式只压缩输出不压缩检查项
- 人类裁决项（页面矛盾/隐性矛盾/反模式触碰）禁止自动裁决，输出清单等人类拍板
- 健康度按公式 `(自动化通过率×50)+((1-反模式触碰率)×50)` 计算，禁止凭感觉打分
- 自动修复项（YAML 格式）修复后必须回显修复结果
